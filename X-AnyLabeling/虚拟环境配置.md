# 项目环境配置指南

本项目推荐在工作区根目录下创建独立的虚拟环境，以确保环境隔离和依赖管理。

## 1. 创建本地虚拟环境 (Conda)

在项目根目录下运行以下命令创建 Conda 环境。建议使用国内镜像源以加快下载速度。

```bash
# 清理索引缓存（可选，若遇到网络问题建议执行）
conda clean -i

# 在当前目录创建名为 conda_X_AnyLabeling_env 的环境
# 指定 Python 版本并使用清华大学镜像源
conda create --prefix ./conda_X_AnyLabeling_env python=3.11 --override-channels -c https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/ -y
```

## 2. 配置编辑器 (VS Code/Trae)

为了让编辑器自动识别并使用该环境，请确保 `.vscode/settings.json` 中包含以下配置：

```json
{
    "python.defaultInterpreterPath": "conda_YOLO_env_V1\\python.exe"
}
```

## 3. 激活与使用

### 激活环境
```bash
conda activate ./conda_X_AnyLabeling_env
```

### 安装依赖
```bash
pip install -r requirements.txt
# 或者
conda install <package_name>
```

### 退出环境
```bash
conda deactivate
```

## 4. 环境管理常用命令

### 查看所有虚拟环境
```bash
conda env list
```
### 注册本地环境到列表
如果 `conda env list` 中没显示本地环境，可以手动注册：
```bash
echo "E:\test\conda_env_V1" >> ~/.conda/environments.txt
```

### 查看当前环境 Python 版本
```bash
python --version
```

## 5. 红色色块检测脚本 (red_detector.py)

该脚本可以检测视频中的红色区域，并将其标记为 `flower`，同时显示置信度和中心坐标。

### 功能
- **实时预览**：边播放视频边显示检测结果及**二进制掩膜（Binary Mask）**。
- **参数调优**：支持实时调节颜色阈值、形态学强度（膨胀/闭运算）及最小面积，以适应不同场景。
- **导出视频**：将处理后的视频保存到本地。
- **目标信息**：显示标签 `flower`、置信度及 `(X, Y)` 二维坐标。

### 安装依赖
```bash
pip install -r requirements.txt
```

### 使用方法

**方式 A：实时播放与调优（推荐）**
使用 `--debug` 参数可以开启参数调节面板，并实时看到 `Result` 和 `Binary Mask` 两个窗口。
```bash
python red_detector.py --input "你的视频路径.mp4" --debug
```

**方式 B：一边识别一边导出视频**
```bash
python red_detector.py --input "你的视频路径.mp4" --output "保存结果路径.mp4"
```

**调优建议：**
1. **Binary Mask 窗口**：如果该窗口全黑，说明颜色阈值（L/A/B）太严苛；如果全白或杂点太多，说明太宽松。
2. **Dilation (膨胀)**：增加该值可以让细小的色块变大，便于连接被遮挡的部分。
3. **Closing (闭运算)**：增加该值可以粘合色块内部的空隙和裂纹。
4. **Min_Area**：如果背景杂点多，适当调大该值以过滤掉小的非花朵区域。

## 常见问题处理

如果遇到 `VenvError` 或 `CondaHTTPError`，通常是由于镜像源连接失败导致的。请尝试：
1. 检查网络连接。
2. 运行 `conda clean -i` 清理缓存。
3. 临时使用 `--override-channels` 参数强制指定可用的镜像源（如清华源）。
